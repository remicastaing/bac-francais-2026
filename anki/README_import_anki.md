# Importer le jeu Anki Bac Français 2026

## Fichier

- `anki/bac_francais_commentaire.csv`

## Import dans Anki

1. Ouvre Anki.
2. Va dans `Fichier` > `Importer`.
3. Choisis le fichier `bac_francais_commentaire.csv`.
4. Crée ou sélectionne le deck `Bac Français 2026`.
5. Vérifie le format de champs : `Recto;Verso;Tags`.
6. Garde le séparateur point-virgule `;`.
7. Laisse l’encodage en UTF-8.
8. Mappe les colonnes sur les champs `Recto`, `Verso` et `Tags`.

## Réglages utiles

- Séparateur : point-virgule.
- Champs : 3.
- Tags : importés tels quels.
- Deck : `Bac Français 2026`.

## Utilisation

- Révise 10 à 15 minutes par jour.
- Commence par 10 à 20 cartes, puis augmente seulement si les révisions restent régulières.
- Revois souvent les cartes difficiles plutôt que d’en ajouter trop.
- Garde une session courte et régulière : c’est plus efficace qu’un gros bloc rare.

## Conseil pratique

- Fais d’abord les cartes de méthode et de procédés.
- Ensuite, ajoute les cartes sur les auteurs, mouvements et registres.
- Termine par les phrases réutilisables et les erreurs fréquentes.
