# Vault bac-francais-2026

Vault Obsidian pour preparer les epreuves anticipees de francais des **10 et 11 juin 2026**.

Objectif : travailler efficacement, avec des fiches courtes, utiles et faciles a relire.

## Acces rapide

- [[dashboard/index]] : tableau de bord principal
- [[suivi/progression]] : suivi de l'avancement
- [[suivi/checklist_globale]] : liste globale des choses a maitriser

## Organisation

- `dashboard/` : point d'entree du vault
- `planning/` : calendrier de revision et objectifs par semaine
- `methodologie/` : methodes pour le commentaire, la dissertation et l'oral
- `procedes/` : fiches sur les procedes litteraires
- `mouvements/` : mouvements litteraires importants
- `auteurs/` : fiches auteurs
- `registres/` : registres litteraires
- `phrases_reutilisables/` : formules utiles pour rediger
- `exercices/` : entrainements personnels
- `commentaires_corriges/` : commentaires corriges et analyses
- `sujets/` : sujets d'entrainement
- `suivi/` : progression, bilans et priorites

## Methode de travail

1. Partir de [[dashboard/index]].
2. Choisir une priorite dans [[suivi/progression]].
3. Travailler une fiche ou un exercice.
4. Mettre a jour [[suivi/checklist_globale]].
5. Noter les difficultes a revoir.

## Regle simple

Une bonne fiche doit etre :

- courte ;
- claire ;
- reutilisable en devoir ;
- reliee aux autres notes avec des liens Obsidian.
