# Index des registres

## Objectif

Retrouver les principaux registres utiles pour enrichir une analyse de commentaire.

## Méthode

Pour utiliser un registre en commentaire, il faut toujours expliquer son effet :

> registre -> effet sur le lecteur -> interprétation.

## Phrase réutilisable

> Le registre [registre] crée un effet de [effet] et permet de montrer que [interprétation].
