# Honoré de Balzac

## Siècle

XIXe siècle.

## Mouvement principal

[[mouvements/realisme]]

## Genres pratiqués

- Roman.
- Nouvelle.

## Thèmes fréquents

- L'argent.
- L'ambition sociale.
- La société.
- Le pouvoir.
- La réussite et l'échec.
- Les milieux sociaux.

## Style

Balzac décrit avec précision les lieux, les objets et les milieux sociaux. Ses descriptions servent souvent à comprendre un personnage ou une classe sociale.

## Procédés fréquents

- [[procedes/enumeration]] pour détailler un décor.
- [[procedes/champ_lexical]] de l'argent ou du pouvoir.
- [[procedes/comparaison]] pour rendre une description concrète.
- [[procedes/metaphore]] pour donner une valeur symbolique aux lieux.

## Œuvres utiles à connaître

- La Comédie humaine.
- Le Père Goriot.
- Eugénie Grandet.

## Phrase courte pour présenter l’auteur

Honoré de Balzac est un romancier réaliste du XIXe siècle qui peint la société française et ses ambitions.

## Phrase réutilisable dans une introduction

Auteur majeur du [[mouvements/realisme]], Balzac utilise la description pour révéler les milieux sociaux et les ambitions de ses personnages.

## Exemple de lien avec un commentaire

Une [[procedes/enumeration]] d'objets dans une description peut montrer le niveau social d'un personnage et annoncer ses valeurs.

## Erreurs à éviter

- Voir la description comme un simple décor.
- Oublier le rôle de l'argent et de l'ambition.
- Ne pas relier les détails à une interprétation.
