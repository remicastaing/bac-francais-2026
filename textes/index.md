## Méthode rapide

Pour chaque extrait, chercher :

- le thème ;
- le ton ou registre ;
- le mouvement ;
- deux procédés utiles ;
- une idée d'axe possible.

## Phrase réutilisable

> Cet extrait peut être analysé comme [idée d'axe], car [procédé] produit un effet de [effet].
