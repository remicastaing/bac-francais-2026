# Checklist globale

Preparation bac francais 2026 - priorite commentaire de texte.

## Priorite absolue

- [ ] Je sais reperer une idee importante dans un texte.
- [ ] Je sais choisir une citation courte.
- [ ] Je sais nommer un procede precis.
- [ ] Je sais expliquer l'effet produit par ce procede.
- [ ] Je sais relier procede -> effet -> interpretation.
- [ ] Je sais rediger une phrase d'analyse complete.
- [ ] Je sais eviter la paraphrase.
- [ ] Je connais la structure generale d'un commentaire.

## Methode du commentaire

- [ ] Je sais lire le texte plusieurs fois avec un objectif precis.
- [ ] Je sais reperer le theme principal du passage.
- [ ] Je sais identifier les mouvements du texte.
- [ ] Je sais distinguer observation, effet et interpretation.
- [ ] Je sais transformer mes reperages en idees d'analyse.
- [ ] Je sais organiser mes idees avant de rediger.
- [ ] Je sais utiliser des citations courtes et utiles.
- [ ] Je sais conclure chaque paragraphe par une interpretation.

## Introduction

- [ ] Je sais presenter rapidement l'auteur sans biographie longue.
- [ ] Je sais presenter l'oeuvre ou le contexte en une ou deux phrases.
- [ ] Je sais situer le passage si l'information est connue.
- [ ] Je sais annoncer l'enjeu du texte.
- [ ] Je sais formuler une problematique claire.
- [ ] Je sais annoncer le plan simplement.
- [ ] Je sais eviter une introduction trop longue.

## Problematique

- [ ] Je sais formuler une question qui commence par "comment" ou "en quoi".
- [ ] Je sais faire une problematique qui correspond vraiment au texte.
- [ ] Je sais eviter les questions trop vagues.
- [ ] Je sais eviter les problematiques qui appellent une reponse oui/non.
- [ ] Je sais relier la problematique aux axes du plan.

## Plan

- [ ] Je sais construire un plan en deux ou trois axes.
- [ ] Je sais donner un titre clair a chaque axe.
- [ ] Je sais eviter les axes qui racontent seulement le texte.
- [ ] Je sais organiser mes axes du plus simple au plus approfondi.
- [ ] Je sais placer les citations dans le bon axe.
- [ ] Je sais faire une transition courte entre deux axes.
- [ ] Je sais garder un fil directeur jusqu'a la conclusion.

## Analyse PECA

- [ ] Je sais trouver le procede.
- [ ] Je sais expliquer l'effet.
- [ ] Je sais choisir une citation courte.
- [ ] Je sais proposer une analyse.
- [ ] Je sais rediger une phrase PECA complete.
- [ ] Je sais transformer une ligne PECA en paragraphe.
- [ ] Je sais varier mes formulations.
- [ ] Je sais verifier que mon interpretation vient bien du texte.

## Procedes litteraires

- [ ] Je connais la comparaison.
- [ ] Je connais la metaphore.
- [ ] Je connais la personnification.
- [ ] Je connais l'anaphore.
- [ ] Je connais la repetition.
- [ ] Je connais l'enumeration.
- [ ] Je connais l'accumulation.
- [ ] Je connais la gradation.
- [ ] Je connais l'antithese.
- [ ] Je connais l'oxymore.
- [ ] Je connais l'hyperbole.
- [ ] Je connais le champ lexical.
- [ ] Je sais donner au moins un effet possible pour chaque procede.

## Registres

- [ ] Je sais reconnaitre le registre lyrique.
- [ ] Je sais reconnaitre le registre tragique.
- [ ] Je sais reconnaitre le registre comique.
- [ ] Je sais reconnaitre le registre polemique.
- [ ] Je sais reconnaitre le registre ironique.
- [ ] Je sais reconnaitre le registre pathetique.
- [ ] Je sais relier un registre a un effet sur le lecteur.
- [ ] Je sais utiliser un registre pour enrichir une interpretation.

## Mouvements litteraires

- [ ] Je connais les grandes idees de l'humanisme.
- [ ] Je connais les grandes idees du classicisme.
- [ ] Je connais les grandes idees des Lumieres.
- [ ] Je connais les grandes idees du romantisme.
- [ ] Je connais les grandes idees du realisme.
- [ ] Je connais les grandes idees du naturalisme.
- [ ] Je connais les grandes idees du symbolisme.
- [ ] Je sais relier un mouvement a un auteur.
- [ ] Je sais relier un mouvement a des themes ou procedes.
- [ ] Je sais utiliser un mouvement sans reciter un cours.

## Auteurs majeurs

- [ ] Je connais une idee utile sur Moliere.
- [ ] Je connais une idee utile sur La Fontaine.
- [ ] Je connais une idee utile sur Voltaire.
- [ ] Je connais une idee utile sur Montesquieu.
- [ ] Je connais une idee utile sur Victor Hugo.
- [ ] Je connais une idee utile sur Balzac.
- [ ] Je connais une idee utile sur Zola.
- [ ] Je connais une idee utile sur Baudelaire.
- [ ] Je connais une idee utile sur Rimbaud.
- [ ] Je sais presenter un auteur en deux phrases maximum.
- [ ] Je sais utiliser un auteur pour eclairer le texte, pas pour faire une biographie.

## Entrainements chronometres

- [ ] J'ai fait au moins un exercice PECA chronometre.
- [ ] J'ai redige au moins un paragraphe de commentaire chronometre.
- [ ] J'ai redige au moins un axe complet chronometre.
- [ ] J'ai fait au moins un commentaire complet en temps limite.
- [ ] J'ai relu et corrige un entrainement complet.
- [ ] J'ai note mes erreurs les plus frequentes.
- [ ] J'ai refait une partie ratee pour progresser.

## Gestion du temps

- [ ] Je sais garder du temps pour lire le texte.
- [ ] Je sais garder du temps pour faire un plan.
- [ ] Je sais ne pas passer trop longtemps sur l'introduction.
- [ ] Je sais rediger des paragraphes efficaces.
- [ ] Je sais garder 10 a 15 minutes pour relire.
- [ ] Je sais quoi faire si je bloque sur un procede.
- [ ] Je sais passer a la suite si une idee ne vient pas.

## Erreurs a eviter

- [ ] Je n'ecris pas une biographie longue.
- [ ] Je ne resume pas le texte au lieu de l'analyser.
- [ ] Je ne fais pas une liste de procedes sans interpretation.
- [ ] Je ne cite pas une phrase trop longue.
- [ ] Je n'oublie pas l'effet produit par le procede.
- [ ] Je n'ecris pas une interpretation sans preuve dans le texte.
- [ ] Je n'annonce pas un plan que je ne respecte pas.
- [ ] Je ne termine pas sans conclusion.
- [ ] Je ne garde pas mes erreurs sans les corriger.

## Derniere verification

- [ ] Je connais mes phrases pretes a reutiliser.
- [ ] Je sais appliquer procede -> effet -> interpretation.
- [ ] Je sais construire un paragraphe clair.
- [ ] Je connais mes priorites pour la veille de l'epreuve.
