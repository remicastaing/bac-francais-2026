# Commentaires partiels

## Consigne

Rédige seulement une partie de commentaire : un axe complet ou deux paragraphes PECA.

Objectif : s'entraîner à rédiger vite, clairement, sans faire un commentaire complet.

## Durée conseillée

45 minutes à 1h15.

## Niveau

Moyen à difficile.

## Exemple

Sujet :

> Comment cette description crée-t-elle une atmosphère inquiétante ?

Plan partiel :

1. Un décor sombre.
2. Une nature rendue vivante et menaçante.

Paragraphe possible :

> Le texte crée d'abord une atmosphère inquiétante grâce au [[procedes/champ_lexical]] de l'obscurité. Les mots "nuit", "ombre" et "silence" plongent le lecteur dans un univers fermé et menaçant. Cette insistance sur le noir donne l'impression que le personnage avance dans un lieu dangereux. Le décor ne sert donc pas seulement à situer l'action : il prépare aussi une tension dramatique.

## Exercices

### Exercice 1

Problématique :

> Comment ce passage suscite-t-il la compassion du lecteur ?

À rédiger :

- Un axe complet.
- Deux paragraphes PECA minimum.

Idées possibles :

- Champ lexical de la souffrance.
- Personnage isolé.
- Description du corps ou du regard.

### Exercice 2

Problématique :

> En quoi cette scène comique critique-t-elle un défaut humain ?

À rédiger :

- Une introduction courte.
- Un axe complet.

Idées possibles :

- Hyperboles.
- Répétitions ou reprises.
- Décalage entre le personnage et les autres.

### Exercice 3

Problématique :

> Comment ce texte transforme-t-il une description réaliste en critique sociale ?

À rédiger :

- Un plan en deux axes.
- Un paragraphe développé.

Idées possibles :

- Détails concrets.
- Champ lexical de la pauvreté.
- Opposition entre richesse et misère.

## Correction ou méthode de correction

Pour corriger, vérifier :

- [ ] L'axe répond bien à la problématique.
- [ ] Le paragraphe commence par une idée claire.
- [ ] Chaque citation est courte.
- [ ] Chaque citation est analysée.
- [ ] Les procédés sont reliés à des effets.
- [ ] Les effets mènent à une interprétation.
- [ ] Il n'y a pas de résumé inutile.

Méthode de correction :

1. Souligner les citations.
2. Entourer les procédés.
3. Surligner les effets.
4. Encadrer les interprétations.
5. Si un paragraphe n'a pas les 4 éléments, le compléter.

## Phrase utile à réutiliser

> Cette analyse confirme l'idée de l'axe : [idée générale].
