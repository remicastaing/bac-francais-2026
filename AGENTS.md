# Consignes pour ce vault

Ce vault sert a preparer le bac francais 2026, surtout l'epreuve du commentaire de texte. Toutes les notes doivent aider un eleve de premiere a reviser vite, comprendre clairement et reutiliser des formulations en devoir.

## Objectif

Permettre une revision efficace pour les epreuves anticipees de francais des **10 et 11 juin 2026**.

Chaque ajout doit servir au moins un de ces objectifs :

- mieux comprendre un texte ;
- construire une analyse de commentaire ;
- memoriser une methode ;
- reutiliser une phrase correcte en devoir ;
- relier un auteur, un mouvement, un procede ou un registre.

## Principes generaux

- Faire des fiches courtes.
- Aller droit a l'essentiel.
- Rester au niveau lycee premiere.
- Eviter le niveau universitaire.
- Ne pas faire de longues biographies.
- Donner des exemples concrets et reutilisables.
- Favoriser les liens internes Obsidian avec un lien vers une note existante, par exemple `[[methodologie/commentaire]]`.
- Garder des titres explicites.
- Utiliser un ton pedagogique, direct et rassurant.

## Regle centrale d'analyse

Dans toute analyse de texte, toujours relier :

**procede -> effet -> interpretation**

Exemple de logique attendue :

- Procede : l'auteur utilise une accumulation.
- Effet : cela donne une impression d'abondance ou d'etouffement.
- Interpretation : le texte insiste sur la violence de la situation ou sur le trouble du personnage.

Phrase reutilisable :

> L'emploi de [procede] produit un effet de [effet], ce qui permet de montrer que [interpretation].

## Format des notes

- Markdown propre.
- Une idee principale par note.
- Listes courtes quand c'est plus lisible.
- Phrases simples.
- Exemples concrets des que possible.
- Citations courtes seulement si elles servent l'analyse.
- Toujours inclure une section `Phrases pretes a reutiliser` quand la note peut aider a rediger.

## Conventions de nommage

Tous les fichiers doivent etre nommes ainsi :

- en minuscules ;
- sans accents ;
- mots separes par des underscores ;
- nom clair et court.

Exemples :

- `victor_hugo.md`
- `romantisme.md`
- `metaphore.md`
- `methode_commentaire_introduction.md`

Les liens internes doivent pointer vers une note existante :

- `[[auteurs/victor_hugo]]`
- `[[mouvements/romantisme]]`
- `[[procedes/metaphore]]`

## Dossiers utiles

- `auteurs/` : fiches auteur courtes.
- `mouvements/` : fiches sur les mouvements litteraires.
- `procedes/` : fiches sur les procedes d'ecriture.
- `methodologie/` : methodes pour commenter, analyser, introduire, conclure.
- `phrases_reutilisables/` : formulations pretes pour la redaction.
- `commentaires_corriges/` : exemples de commentaires ou plans corriges.
- `exercices/` : entrainements courts.

## Structure standard : fiche auteur

Une fiche auteur doit rester courte. Elle ne doit pas devenir une biographie complete.

Structure attendue :

```markdown
# nom_de_l_auteur

## A retenir

- Siecle :
- Mouvement(s) possible(s) :
- Genres principaux :
- Oeuvres utiles :
- Idee importante :

## Ce qui peut servir en commentaire

- Theme frequent :
- Vision du monde :
- Type d'ecriture :
- Lien possible avec un mouvement existant :

## Procedes frequents

- [procede] -> [effet] -> [interpretation]
- [procede] -> [effet] -> [interpretation]

## Exemple d'analyse

Dans un texte de [auteur], [procede] peut produire un effet de [effet]. Cela montre que [interpretation].

## Phrases pretes a reutiliser

- Chez [auteur], [theme] permet souvent de montrer [idee].
- Ce passage peut etre rapproche de [mouvement] car il met en valeur [idee].
- L'ecriture de [auteur] cherche ici a [effet sur le lecteur].

## Liens utiles

- lien vers un mouvement existant
- lien vers un theme existant si la note existe
- lien vers un procede existant
```

## Structure standard : fiche mouvement

Une fiche mouvement doit aider a reconnaitre le mouvement dans un texte et a l'utiliser dans une interpretation.

Structure attendue :

```markdown
# nom_du_mouvement

## Definition simple

[Definition en 2 ou 3 phrases maximum.]

## Periode

- Siecle :
- Contexte utile :

## Caracteristiques principales

- [idee 1]
- [idee 2]
- [idee 3]

## Auteurs utiles

- lien vers un auteur existant
- lien vers un autre auteur existant

## Procedes frequents

- [procede] -> [effet] -> [interpretation]
- [procede] -> [effet] -> [interpretation]

## Exemple d'analyse

Ce texte peut se rattacher a [mouvement] car [procede ou theme] met en valeur [interpretation].

## Phrases pretes a reutiliser

- Ce passage reprend une caracteristique de [mouvement] : [idee].
- Le texte s'inscrit dans [mouvement] car il insiste sur [theme].
- Cette ecriture cherche a [effet], ce qui correspond a [idee du mouvement].

## Liens utiles

- lien vers un auteur existant
- lien vers un procede existant
- lien vers un registre existant
```

## Structure standard : fiche procede

Une fiche procede doit toujours aider a passer du reperage a l'interpretation.

Structure attendue :

```markdown
# nom_du_procede

## Definition simple

[Definition courte et claire.]

## Comment le reperer

- Indice 1 :
- Indice 2 :

## Effets possibles

- [effet 1]
- [effet 2]
- [effet 3]

## Interpretations possibles

- Peut montrer [idee].
- Peut souligner [idee].
- Peut renforcer [idee].

## Exemple complet

Citation courte : "[citation]"

- Procede : [nom du procede]
- Effet : [effet produit]
- Interpretation : [ce que cela montre dans le texte]

Phrase redigee :

> L'emploi de [procede] produit un effet de [effet], ce qui souligne [interpretation].

## Phrases pretes a reutiliser

- Ce procede met en valeur [idee].
- Ce choix d'ecriture renforce l'impression de [effet].
- Grace a [procede], le lecteur ressent [effet], ce qui montre [interpretation].

## Erreurs a eviter

- Ne pas seulement nommer le procede.
- Ne pas oublier son effet.
- Ne pas proposer une interpretation sans lien avec le texte.
```

## Structure standard : fiche methodologie

Une fiche methodologie doit etre directement applicable en devoir ou en entrainement.

Structure attendue :

```markdown
# methode_[objectif]

## Objectif

[Dire en une phrase a quoi sert cette methode.]

## Quand l'utiliser

- [situation 1]
- [situation 2]

## Methode pas a pas

1. [etape 1]
2. [etape 2]
3. [etape 3]

## Checklist rapide

- [ ] J'ai repere les idees principales.
- [ ] J'ai releve des procedes precis.
- [ ] J'ai relie procede -> effet -> interpretation.
- [ ] J'ai formule une idee claire.
- [ ] J'ai garde un niveau de langue correct.

## Exemple court

[Exemple simple, avec une phrase redigee.]

## Phrases pretes a reutiliser

- Nous pouvons nous demander comment [problematique].
- Dans un premier temps, le texte montre [idee].
- Ce procede permet de comprendre que [interpretation].
- Ainsi, le passage met en valeur [bilan].

## Erreurs a eviter

- Reciter le cours sans analyser le texte.
- Faire une liste de procedes sans interpretation.
- Ecrire des phrases trop longues.
- Oublier de citer le texte.
```

## Attendus pour le commentaire de texte

Pour toute note liee au commentaire, privilegier :

- la methode d'analyse ;
- la construction d'axes ;
- les transitions simples ;
- les phrases d'introduction et de conclusion ;
- les formulations pour analyser une citation ;
- les exemples transferables a plusieurs textes.

Formule de base a encourager :

> Dans cette citation, [auteur] utilise [procede]. Ce choix cree un effet de [effet]. Il permet de comprendre que [interpretation].

## Ton attendu

- Clair.
- Direct.
- Pedagogique.
- Rassurant.
- Oriente methode et reussite aux epreuves.

Ne pas dramatiser les difficultes. Donner des solutions simples et applicables.
