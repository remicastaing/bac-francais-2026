# Synthèse imprimable - bac français 2026

Révision de dernière minute avant les épreuves des **10 et 11 juin 2026**.

## Méthode du commentaire en 1 page

Objectif : expliquer comment le texte produit du sens.

1. Lire le texte 3 fois.
2. Repérer le genre, le thème, le ton, les mouvements du texte.
3. Relever des citations courtes.
4. Associer chaque citation à un procédé.
5. Relier toujours : **procédé -> effet -> interprétation**.
6. Regrouper les analyses en 2 ou 3 axes.
7. Formuler une problématique avec "comment" ou "en quoi".
8. Rédiger : introduction, développement, conclusion.
9. Relire pour supprimer la paraphrase.

Répartition en 4h :

| Étape | Temps |
| --- | --- |
| Lecture + repérages | 1h |
| Plan + problématique | 30 min |
| Rédaction | 2h15 |
| Relecture | 15 min |

## Phrases utiles

- Dans cet extrait, l'auteur met en scène [situation].
- Nous pouvons nous demander comment [problématique].
- Dans un premier temps, le texte montre [axe 1], puis il révèle [axe 2].
- L'emploi de [procédé] produit un effet de [effet].
- Ce procédé met en valeur [idée].
- L'auteur donne ainsi au lecteur l'impression que [effet].
- Cette opposition souligne [interprétation].
- Le texte progresse donc d'une description vers [interprétation].
- Ainsi, le passage montre que [réponse à la problématique].

## Erreurs à éviter

- Résumer le texte au lieu de l'analyser.
- Faire une biographie longue.
- Citer une phrase trop longue.
- Nommer un procédé sans expliquer son effet.
- Oublier l'interprétation.
- Faire un plan ligne par ligne.
- Écrire une problématique trop vague.
- Ne pas garder de temps pour relire.
